Practical Data Structures Applied

This project demonstrates theoretical Computer Science concepts in a production-ready application context:

FIFO Queue (O(1)) collections.deque for pending complaints order.
Merge Sort (O(n log n)) Recursive divide-and-conquer sorting by submission timestamp.
Linear Search (O(n)) Search by complaint ID or passenger name across records.
Dict & Set Validation O(1) category validation sets and category frequency counters.
